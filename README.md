# FilaCero

**Avanza tu trámite, no tu espera.**

Plataforma web para que los alumnos agenden citas, revisen requisitos y den seguimiento a sus trámites en la coordinación, sin hacer fila.

Proyecto de Ingeniería de Software · Universidad de Sonora · Ingeniería en Sistemas de Información.

## Probar el prototipo

Abre la página publicada y entra con la cuenta de demostración (botón "Usar cuenta de demostración"), o crea una cuenta. En el prototipo el código de verificación es `123456`.
